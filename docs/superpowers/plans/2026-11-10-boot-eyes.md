# Boot Eyes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Orbs 2 and 4 show a pair of eyes that wake up groggily while WiFi connects, come fully awake when it connects, then hand over to the clock.

**Architecture:** `WakeScript` is a pure, header-only keyframe script: time plus "connected" in, eye pose out. `EyeRenderer` draws one Uncanny Eye pixel-doubled to a 240×240 panel. `BootEyes` runs a FreeRTOS task that draws both eyes only while `WifiWidget::connect()` blocks, so nothing else draws at the same time and no locks around TFT_eSPI are needed. A `-D BOOT_EYES` build flag and an NVS key `booteyes` (default on) gate it.

**Tech Stack:** PlatformIO, Arduino-ESP32 (platform espressif32 @ 7.0.1), TFT_eSPI 2.5.43, FreeRTOS, Unity for host tests.

**Spec:** `docs/superpowers/specs/2026-11-10-boot-eyes-design.md`

## Global Constraints

- Boards: XIAO ESP32-S3 / S3 Plus (`env:xiao-esp32s3`, `ota`, `release`). `env:supermini-proto` builds **without** the eyes (`build_unflags = -D BOOT_EYES`).
- **DMA stays off.** On this board (USE_HSPI_PORT, ESP32-S3) it gave all-black screens, and it gave no speed gain. Use plain `pushPixels`.
- Eye: `defaultEye` from TFT_eSPI `examples/Generic/Animated_Eyes_2/data/defaultEye.h`. Keep the Adafruit / Phil Burgess MIT notice.
- Scale: 2× pixel doubling, crop 4 source px per side, address window (0,0,240,240).
- Lid colors (RGB): skin `170,143,129`, shadow `128,106,95`, lash `30,22,20`.
- Lid geometry, in lid-map units except where marked:
  - LASH_W 6, SHADOW_W 14, LASH_LEN 45.
  - Lash spacing 6 source px; outward fan 5/16.
- Screen indices are logical and in the viewer's order: index 1 = orb 2 (left eye), index 3 = orb 4 (right eye). `ScreenManager::selectScreen` already reverses the chip-select order when `invert` is set, so the eyes need no swap for upside-down mounting.
- NVS key `booteyes`, a bool, default `true`. An absent key means the default.
- With the setting off, or without `BOOT_EYES`, every screen draws exactly what it draws today.
- Public repo: no site details (IP addresses, names, SSIDs) in code, docs or commit messages.
- US English. Code style follows `.clang-format` (LLVM, 4-space indent).
- Commit at each task's end; the message says what was rejected and why. End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push without Scott's go.

| `firmware/src/main.cpp` | Splash text placement, eyes start/finish around `connect()`. |
| `docs/SETUP.md`, `README.md` | One line each on the new setting. |

**Deviations from the spec,** decided while reading the code; the spec is amended in the same commit as this plan:
1. The setting is an On/Off `<select>` in a new "Start-up" fieldset of the main settings form, not a checkbox in the "Start-up picture" fieldset. That fieldset sits outside the main `<form>` (it has its own upload forms), and every other bool on the page is a `boolSelect`.
2. There is no host test for the NVS key: `Settings.cpp` uses `Preferences`, which the native env cannot compile. The default and the round trip are checked on the rig.
3. There is no `ci_build.sh`. "Build every env" means the `pio run -e …` commands listed in Task 5, Step 6.
4. `invert` needs no eye swap, because `selectScreen` already maps logical indices to the viewer's order.

```cpp
// Host tests for WakeScript.h:  pio test -e native -f test_booteyes
#include "WakeScript.h"
#include <unity.h>

void setUp() {}
void tearDown() {}

static const uint32_t T0 = 100000; // begin() time; not zero, to catch "since start" bugs

static WakeScript started() {
    WakeScript s;
    s.begin(T0);
    return s;
}

void test_intro_starts_shut_and_looking_down() {
    WakeScript s = started();
    EyePose p = s.at(T0);
    TEST_ASSERT_EQUAL(0, p.open);
    TEST_ASSERT_EQUAL(512, p.gazeX);
    TEST_ASSERT_EQUAL(380, p.gazeY);
    TEST_ASSERT_FALSE(p.done);
}

void test_intro_keyframes() {
    WakeScript s = started();
    TEST_ASSERT_EQUAL(0, s.at(T0 + 1500).open);
    TEST_ASSERT_EQUAL(70, s.at(T0 + 2600).open); // first crack open
    TEST_ASSERT_EQUAL(60, s.at(T0 + 3200).open);
    TEST_ASSERT_EQUAL(0, s.at(T0 + 3500).open);
    TEST_ASSERT_EQUAL(0, s.at(T0 + 3900).open);
    TEST_ASSERT_EQUAL(400, s.at(T0 + 3900).gazeY);
}

void test_loop_keyframes_and_period() {
    WakeScript s = started();
    const uint32_t L = T0 + 3900; // loop start
    TEST_ASSERT_EQUAL(110, s.at(L + 1000).open);
    TEST_ASSERT_EQUAL(90, s.at(L + 1700).open);
    TEST_ASSERT_EQUAL(420, s.at(L + 1700).gazeY);
    TEST_ASSERT_EQUAL(150, s.at(L + 2100).open);
    TEST_ASSERT_EQUAL(40, s.at(L + 2700).open);
    for (uint32_t t = 0; t < 3000; t += 37) {
        EyePose a = s.at(L + t), b = s.at(L + 3000 + t), c = s.at(L + 30000 + t);
        TEST_ASSERT_EQUAL(a.open, b.open);
        TEST_ASSERT_EQUAL(a.open, c.open);
        TEST_ASSERT_EQUAL(a.gazeY, c.gazeY);
    }
}

void test_never_done_without_connect() {
    WakeScript s = started();
    TEST_ASSERT_FALSE(s.at(T0 + 600000).done);
}

void test_early_connect_waits_for_first_crack_open() {
    WakeScript s = started();
    s.connected(T0 + 1000);
    TEST_ASSERT_EQUAL(WakeScript::groggy(2599).open, s.at(T0 + 2599).open); // still groggy
    EyePose p = s.at(T0 + 2600 + 300);                                      // finale t = 300
    TEST_ASSERT_EQUAL(170, p.open);
    TEST_ASSERT_EQUAL(512, p.gazeX);
    TEST_ASSERT_EQUAL(512, p.gazeY);
    TEST_ASSERT_TRUE(s.at(T0 + 2600 + 2000).done);
    TEST_ASSERT_FALSE(s.at(T0 + 2600 + 1999).done);
}

void test_finale_keyframes_and_end() {
    WakeScript s = started();
    const uint32_t C = T0 + 5000;
    s.connected(C);
    TEST_ASSERT_EQUAL(180, s.at(C + 700).gazeX);  // look one way
    TEST_ASSERT_EQUAL(850, s.at(C + 1300).gazeX); // then the other
    TEST_ASSERT_EQUAL(0, s.at(C + 1600).open);    // quick blink
    EyePose end = s.at(C + 2000);
    TEST_ASSERT_TRUE(end.done);
    TEST_ASSERT_EQUAL(256, end.open);
    TEST_ASSERT_EQUAL(512, end.gazeX);
    TEST_ASSERT_EQUAL(512, end.gazeY);
    TEST_ASSERT_TRUE(s.at(C + 60000).done); // stays done
}

void test_handoff_is_continuous() {
    const uint32_t connects[] = {500, 2600, 3000, 4500, 5200, 6800, 9000, 12345};
    for (uint32_t c : connects) {
        WakeScript s = started();
        s.connected(T0 + c);
        const uint32_t f = c > 2600 ? c : 2600; // finale start, ms since begin
        EyePose g = WakeScript::groggy(f), p = s.at(T0 + f);
        TEST_ASSERT_INT_WITHIN(1, g.open, p.open);
        TEST_ASSERT_INT_WITHIN(1, g.gazeX, p.gazeX);
        TEST_ASSERT_INT_WITHIN(1, g.gazeY, p.gazeY);
    }
}

void test_second_connect_is_ignored() {
    WakeScript s = started();
    s.connected(T0 + 5000);
    s.connected(T0 + 9000);
    TEST_ASSERT_TRUE(s.at(T0 + 7000).done);
}

int main() {
    UNITY_BEGIN();
    RUN_TEST(test_intro_starts_shut_and_looking_down);
    RUN_TEST(test_intro_keyframes);
    RUN_TEST(test_loop_keyframes_and_period);
    RUN_TEST(test_never_done_without_connect);
    RUN_TEST(test_early_connect_waits_for_first_crack_open);
    RUN_TEST(test_finale_keyframes_and_end);
    RUN_TEST(test_handoff_is_continuous);
    RUN_TEST(test_second_connect_is_ignored);
    return UNITY_END();
}
```

```cpp
#pragma once
// Keyframe script for the boot eyes (docs/superpowers/specs/2026-11-10-boot-eyes-design.md):
// groggy while WiFi connects, then a 2 s finale once it has. Pure logic with no
// Arduino calls, so test/test_booteyes runs it on the host.
#include <cstddef>
#include <cstdint>

struct EyePose {
    uint16_t open; // 0 = lids shut, 256 = lids free (normal tracking)
    int16_t gazeX; // 0..1023, 512 = center
    int16_t gazeY; // 0..1023, 512 = center, low = looking down
    bool done;     // finale finished
};

namespace wake {
struct Key {
    uint32_t ms;
    int16_t v;
};
struct GazeKey {
    uint32_t ms;
    int16_t x, y;
};

// Groggy intro, once from begin()
static const Key kIntroOpen[] = {{0, 0}, {1500, 0}, {2600, 70}, {3200, 60}, {3500, 0}, {3900, 0}};
static const GazeKey kIntroGaze[] = {{0, 512, 380}, {3900, 512, 400}};
// Groggy loop, repeating from kIntroMs until connected
static const Key kLoopOpen[] = {{0, 0}, {1000, 110}, {1700, 90}, {2100, 150}, {2700, 40}, {3000, 0}};
static const GazeKey kLoopGaze[] = {{0, 512, 400}, {1700, 512, 420}, {3000, 512, 400}};
// Finale, ms from its start. 0..kEaseMs eases from the groggy pose to the first key.
static const Key kFinaleOpen[] = {{300, 170}, {1500, 170}, {1600, 0}, {1800, 256}, {2000, 256}};
static const GazeKey kFinaleGaze[] = {{300, 512, 512},  {700, 180, 520},  {1000, 180, 520}, {1300, 850, 520},
                                      {1600, 850, 520}, {1800, 512, 512}, {2000, 512, 512}};

constexpr uint32_t kIntroMs = 3900;
constexpr uint32_t kLoopMs = 3000;
constexpr uint32_t kEarliestFinaleMs = 2600; // the first crack open always shows
constexpr uint32_t kEaseMs = 300;
constexpr uint32_t kFinaleMs = 2000;

inline int32_t smooth(uint32_t t, uint32_t t0, int32_t v0, uint32_t t1, int32_t v1) {
    if (t1 <= t0) {
        return v1;
    }
    float f = float(t - t0) / float(t1 - t0);
    f = f * f * (3 - 2 * f); // smoothstep
    return v0 + int32_t((v1 - v0) * f);
}

// Value of a keyframe track at t; holds the first/last value outside it
template <typename K, typename Get>
inline int32_t track(const K *k, size_t n, uint32_t t, Get get) {
    if (t <= k[0].ms) {
        return get(k[0]);
    }
    for (size_t i = 0; i + 1 < n; i++) {
        if (t < k[i + 1].ms) {
            return smooth(t, k[i].ms, get(k[i]), k[i + 1].ms, get(k[i + 1]));
        }
    }
    return get(k[n - 1]);
}

template <typename K, size_t N>
constexpr size_t countOf(const K (&)[N]) {
    return N;
}
} // namespace wake

class WakeScript {
  public:
    void begin(uint32_t nowMs) {
        m_start = nowMs;
        m_connected = false;
    }

    void connected(uint32_t nowMs) {
        if (m_connected) {
            return;
        }
        m_connected = true;
        const uint32_t since = nowMs - m_start;
        m_finaleAt = since > wake::kEarliestFinaleMs ? since : wake::kEarliestFinaleMs;
        m_from = groggy(m_finaleAt);
    }

    EyePose at(uint32_t nowMs) const {
        const uint32_t t = nowMs - m_start;
        if (!m_connected || t < m_finaleAt) {
            return groggy(t);
        }
        return finale(t - m_finaleAt);
    }

    // t = ms since begin()
    static EyePose groggy(uint32_t t) {
        using namespace wake;
        auto v = [](const Key &k) { return int32_t(k.v); };
        auto x = [](const GazeKey &k) { return int32_t(k.x); };
        auto y = [](const GazeKey &k) { return int32_t(k.y); };
        if (t < kIntroMs) {
            return {uint16_t(track(kIntroOpen, countOf(kIntroOpen), t, v)), int16_t(track(kIntroGaze, countOf(kIntroGaze), t, x)),
                    int16_t(track(kIntroGaze, countOf(kIntroGaze), t, y)), false};
        }
        const uint32_t l = (t - kIntroMs) % kLoopMs;
        return {uint16_t(track(kLoopOpen, countOf(kLoopOpen), l, v)), int16_t(track(kLoopGaze, countOf(kLoopGaze), l, x)),
                int16_t(track(kLoopGaze, countOf(kLoopGaze), l, y)), false};
    }

  private:
    EyePose finale(uint32_t f) const {
        using namespace wake;
        if (f >= kFinaleMs) {
            return {256, 512, 512, true};
        }
        if (f < kEaseMs) {
            const Key &o = kFinaleOpen[0];
            const GazeKey &g = kFinaleGaze[0];
            return {uint16_t(smooth(f, 0, m_from.open, kEaseMs, o.v)), int16_t(smooth(f, 0, m_from.gazeX, kEaseMs, g.x)),
                    int16_t(smooth(f, 0, m_from.gazeY, kEaseMs, g.y)), false};
        }
        auto v = [](const Key &k) { return int32_t(k.v); };
        auto x = [](const GazeKey &k) { return int32_t(k.x); };
        auto y = [](const GazeKey &k) { return int32_t(k.y); };
        return {uint16_t(track(kFinaleOpen, countOf(kFinaleOpen), f, v)), int16_t(track(kFinaleGaze, countOf(kFinaleGaze), f, x)),
                int16_t(track(kFinaleGaze, countOf(kFinaleGaze), f, y)), false};
    }

    uint32_t m_start{0};
    bool m_connected{false};
    uint32_t m_finaleAt{0}; // ms since begin()
    EyePose m_from{0, 512, 512, false};
};
```

```cpp
#pragma once
// Draws one "Uncanny Eyes" eye (Phil Burgess / Adafruit, MIT; via TFT_eSPI's
// Animated_Eyes_2) pixel-doubled to fill a 240x240 orb, with skin-colored lids
// and lashes. DMA stays off: on this board it gave all-black screens.
#include "WakeScript.h"
#include <TFT_eSPI.h>

class EyeRenderer {
  public:
    explicit EyeRenderer(TFT_eSPI &tft);
    // side 0 = left eye (orb 2), 1 = right eye (orb 4). The caller has
    // selected the panel. Returns false if *abort became true mid-frame (the
    // frame is then left part-drawn; the caller blanks the orb).
    bool draw(uint8_t side, const EyePose &pose, const volatile bool *abort);

  private:
    TFT_eSPI &m_tft;
```

```cpp
#ifdef BOOT_EYES
    #include "EyeRenderer.h"
    #include <Arduino.h>

namespace eyedata {
    #include "eyeData.h"
}
using namespace eyedata;

namespace {
constexpr int kCrop = 4;             // 128 - 2*4 = 120 source px -> 240 panel px
constexpr uint32_t kIrisScale = 110; // fixed pupil: midpoint of the example's IRIS_MIN..IRIS_MAX (90..130)
// Lids, in lid-map units: margin past the closing threshold, small = lid edge
constexpr int32_t kLashW = 6;     // lash line
constexpr int32_t kShadowW = 14;  // shadow band after it
constexpr int32_t kLashLen = 45;  // lash strands, upper lid only
constexpr int32_t kLashSp = 6;    // strand spacing, source px
constexpr int32_t kLashFan16 = 5; // outward lean, x16
} // namespace

EyeRenderer::EyeRenderer(TFT_eSPI &tft) : m_tft(tft) {
    m_skin = tft.color565(170, 143, 129); // "Taupe", chosen on the rig 2026-11-10
    m_shadow = tft.color565(128, 106, 95);
    m_lash = tft.color565(30, 22, 20);
}

bool EyeRenderer::draw(uint8_t side, const EyePose &pose, const volatile bool *abort) {
    // Gaze 0..1023 -> window offset into the 200x200 sclera, slightly converged
    int32_t eyeX = map(pose.gazeX, 0, 1023, 0, SCLERA_WIDTH - SCREEN_WIDTH) + (side ? 4 : -4);
    int32_t eyeY = map(pose.gazeY, 0, 1023, 0, SCLERA_HEIGHT - SCREEN_HEIGHT);
    eyeX = constrain(eyeX, 0, SCLERA_WIDTH - SCREEN_WIDTH);
    eyeY = constrain(eyeY, 0, SCLERA_HEIGHT - SCREEN_HEIGHT);

    // Upper lid tracks the pupil (sampled just above it); the lower lid follows
    const int32_t sampleX = SCLERA_WIDTH / 2 - eyeX / 2;
    const int32_t sampleY = SCLERA_HEIGHT / 2 - (eyeY + IRIS_HEIGHT / 4);
    uint32_t n = 0;
    if (sampleY >= 0) {
        n = (pgm_read_byte(upper + sampleY * SCREEN_WIDTH + sampleX) +
             pgm_read_byte(upper + sampleY * SCREEN_WIDTH + (SCREEN_WIDTH - 1 - sampleX))) /
            2;
    }
    m_uThreshold[side] = (m_uThreshold[side] * 3 + n) / 4;
    uint32_t uT = m_uThreshold[side];
    uint32_t lT = 254 - uT;
    // The script closes the lids over the tracking: 254 = shut
    const uint32_t open = pose.open > 256 ? 256 : pose.open;
    uT = (uT * open + 254 * (256 - open)) / 256;
    lT = (lT * open + 254 * (256 - open)) / 256;

    const bool swap = m_tft.getSwapBytes();
    m_tft.setSwapBytes(false); // bytes are swapped by hand below, as in the example
    m_tft.startWrite();
    m_tft.setAddrWindow(0, 0, 240, 240);

    uint32_t scleraY = eyeY;
    int32_t irisY = eyeY - (SCLERA_HEIGHT - IRIS_HEIGHT) / 2;
    const int16_t dLidX = side ? 1 : -1; // lid maps are mirrored for the left eye
    bool finished = true;
    for (int screenY = 0; screenY < SCREEN_HEIGHT; screenY++, scleraY++, irisY++) {
        if (screenY < kCrop || screenY >= SCREEN_HEIGHT - kCrop) {
            continue;
        }
        if (abort && *abort) {
            finished = false;
            break;
        }
        uint32_t scleraX = eyeX;
        int32_t irisX = eyeX - (SCLERA_WIDTH - IRIS_WIDTH) / 2;
        int16_t lidX = side ? 0 : SCREEN_WIDTH - 1;
        uint16_t o = 0;
        for (int screenX = 0; screenX < SCREEN_WIDTH; screenX++, scleraX++, irisX++, lidX += dLidX) {
            if (screenX < kCrop || screenX >= SCREEN_WIDTH - kCrop) {
                continue;
            }
            const uint32_t vLo = pgm_read_byte(lower + screenY * SCREEN_WIDTH + lidX);
            const uint32_t vUp = pgm_read_byte(upper + screenY * SCREEN_WIDTH + lidX);
            uint32_t p;
            if (vLo <= lT || vUp <= uT) {
                const int32_t mU = (vUp <= uT) ? int32_t(uT) - int32_t(vUp) : 9999;
                const int32_t mL = (vLo <= lT) ? int32_t(lT) - int32_t(vLo) : 9999;
                const int32_t m = mU < mL ? mU : mL;
                const bool upperHit = (vUp <= uT) && (mU <= mL);
                p = (m < kLashW + kShadowW) ? m_shadow : m_skin;
                if (m < kLashW) {
                    p = m_lash; // lash line
                } else if (upperHit && m < kLashW + kLashLen) { // strands, fanning out
                    const int32_t k = m - kLashW;
                    const int32_t ox = int32_t(screenX) - 64;
                    const int32_t sx = int32_t(screenX) * 16 - (ox * k * kLashFan16) / 64;
                    const int32_t per = kLashSp * 16;
                    const int32_t ph = ((sx % per) + per) % per;
                    const int32_t th = (k < kLashLen / 2) ? 24 : 14; // taper, x16 px
                    if (ph < th) {
                        p = m_lash;
                    }
                }
            } else if (irisY < 0 || irisY >= IRIS_HEIGHT || irisX < 0 || irisX >= IRIS_WIDTH) {
                p = pgm_read_word(sclera + scleraY * SCLERA_WIDTH + scleraX);
            } else {
                p = pgm_read_word(polar + irisY * IRIS_WIDTH + irisX);
                const uint32_t d = (kIrisScale * (p & 0x7F)) / 128;
                if (d < IRIS_MAP_HEIGHT) {
                    const uint32_t a = (IRIS_MAP_WIDTH * (p >> 7)) / 512;
                    p = pgm_read_word(iris + d * IRIS_MAP_WIDTH + a);
                } else {
                    p = pgm_read_word(sclera + scleraY * SCLERA_WIDTH + scleraX);
                }
            }
            const uint16_t q = uint16_t(p >> 8 | p << 8);
            m_line[o++] = q;
            m_line[o++] = q;
        }
        m_tft.pushPixels(m_line, 240);
        m_tft.pushPixels(m_line, 240);
    }
    m_tft.endWrite();
    m_tft.setSwapBytes(swap);
    return finished;
}
```

```cpp
#ifdef BOOT_EYES
    #include "BootEyes.h"
    #include "EyeRenderer.h"
    #include "WakeScript.h"
    #include <Arduino.h>
    #include <new>

namespace {
constexpr int kLeftScreen = 1;  // orb 2
constexpr int kRightScreen = 3; // orb 4
// Longest legitimate wait: connected at t ~ 0, then 2.6 s to the first crack
// open plus the 2 s finale
constexpr uint32_t kFinishTimeoutMs = 6000;

ScreenManager *s_sm = nullptr;
EyeRenderer *s_renderer = nullptr;
WakeScript s_script;
SemaphoreHandle_t s_lock = nullptr; // guards s_script: the task reads, finish() writes
TaskHandle_t s_task = nullptr;
volatile bool s_stop = false;
volatile bool s_exited = false;

EyePose currentPose() {
    xSemaphoreTake(s_lock, portMAX_DELAY);
    const EyePose p = s_script.at(millis());
    xSemaphoreGive(s_lock);
    return p;
}

void eyeTask(void *) {
    while (!s_stop) {
        const EyePose pose = currentPose();
        s_sm->selectScreen(kLeftScreen);
        if (!s_renderer->draw(0, pose, &s_stop)) {
            break;
        }
        s_sm->selectScreen(kRightScreen);
        if (!s_renderer->draw(1, pose, &s_stop)) {
            break;
        }
        if (pose.done) {
            break;
        }
        vTaskDelay(1); // let the idle task feed the watchdog
    }
    s_exited = true; // last touch of shared state
    vTaskDelete(nullptr);
}

void release() {
    delete s_renderer;
    s_renderer = nullptr;
    if (s_lock) {
        vSemaphoreDelete(s_lock);
        s_lock = nullptr;
    }
    s_task = nullptr;
}
} // namespace

bool BootEyes::start(ScreenManager &sm, TFT_eSPI &tft) {
    s_sm = &sm;
    s_lock = xSemaphoreCreateMutex();
    s_renderer = new (std::nothrow) EyeRenderer(tft);
    s_stop = false;
    s_exited = false;
    if (s_lock && s_renderer) {
        s_script.begin(millis());
        // Core 1 beside loopTask (blocked in autoConnect); WiFi runs on core 0
        if (xTaskCreatePinnedToCore(eyeTask, "booteyes", 6144, nullptr, 1, &s_task, 1) == pdPASS) {
            return true;
        }
    }
    Serial.println("Boot eyes: could not start (out of memory)");
    release();
    return false;
}

void BootEyes::finish(bool connected) {
    if (!s_task) {
        return;
    }
    if (connected) {
        xSemaphoreTake(s_lock, portMAX_DELAY);
        s_script.connected(millis());
        xSemaphoreGive(s_lock);
        const uint32_t t0 = millis();
        while (!s_exited && millis() - t0 < kFinishTimeoutMs) {
            delay(10);
        }
        if (!s_exited) {
            Serial.println("Boot eyes: finale overran, stopping");
        }
    }
    s_stop = true; // checked between lines, never mid-transaction
    while (!s_exited) {
        delay(5);
    }
    if (!connected) {
        s_sm->clearScreen(kLeftScreen);
        s_sm->clearScreen(kRightScreen);
    }
    release();
}
#endif // BOOT_EYES
```

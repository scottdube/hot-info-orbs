# Enclosure print files

**Not ready yet.** The enclosure is still being designed, so there is nothing
to print here. When it is finished, this folder will hold one ready-to-print
file per part (`.3mf`, which opens in Bambu Studio, PrusaSlicer and Orca
Slicer), with the material, color and print settings for each.

From the current design ([docs/ENCLOSURE.md](../../../docs/ENCLOSURE.md)).
The list may change as the design does.

## Filament

Any filament can be used.  The prototypes of this enclosure were printed using PLA.
The body was printed using a matte finish filament to contrast against the silk finish of the bezels, buttons, and wings.  

The exact filaments used:
* Polymaker Panchroma Matte PLA Army Blue (CA04008)
* Polymaker Panchroma Silk PLA Gold (CA03006) - gold tint is more orange than the rendering at the top of the page

Polymaker filament presets for your printer can be downloaded from https://presets.polymaker.com/

## Printing Tips

Overall: For the best finish, use 0.08 mm or minimum layer height with standard 0.4 mm nozzle.

| Component | Setting (may vary based on slicer) |
|---|---|
| main body front & back |	Enable support:	On (tree(auto), default style) |
| main body front & back |	Wall sequence:	Outer wall / inner |
| main body front & back | Variable layer height: Adaptive (Quality/Speed: 0, Radius: 10), Smooth x5, Keep min |
| wings right & left, buttons, all bezels | Seam position: Random |
